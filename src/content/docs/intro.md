description: How to use this boilerplate.
---

This is a basic displayable [Starlight](https://starlight.astro.build/) boilerplate. It includes:

- A splash home page (`src/content/docs/index.mdx`)
- This intro page (`src/content/docs/intro.md`)
- A tiny blog in `src/content/docs/blog/`
- A pinch of custom CSS (`src/styles/custom.css`)

## Add a page

Create a Markdown file in `src/content/docs/` with `title` front matter. It shows up in the sidebar if you list it in `astro.config.mjs` or put it in an autogenerated directory.

## Add a blog post

Create a file in `src/content/docs/blog/`, for example `my-post.md`:

```md
---
title: My Post
description: What it's about.
date: 2026-03-01
---

Hello, world!
```

Run `npm run dev` to preview, `npm run build` to build to `dist/`.
